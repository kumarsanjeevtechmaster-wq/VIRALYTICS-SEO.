VIRALYTICS · DESKTOP SETUP · 5 MINUTES + 1 CHOTI INSTALL

Desktop par set up —
step by step,
technical jhanjhat ke bina

Aapko "technical" nahi lagta? Bilkul theek hai — isi liye ye booklet hai. Neeche har step likha hai: kahan karna hai, kya dikhega, aur kuch galat ho to kya karna hai. Sirf 3 cheezein karni hain — zip kholo, ek chhota free program (Node.js) install karo, ek file double-click karo.

Poora kaam:  Step 1: Zip kholo  ·  Step 2: Node.js install (free)  ·  Step 3: start-server double-click  ·  Step 4: pehli report banao

Cost:  ₹0  ·  Time:  ~10 minute pehli baar, uske baad roz 10 second  ·  Python ab zaroorat nahi

0Pehle samajh lo — yahan kya-kya hai

Jo aapne zip download ki hai, uske andar 5 zaroori cheezein hain. Baaki sab tools hain (wo aapko touch karne ki zaroorat nahi):

Ek baat pakka yaad rakhoKabhi bhi doosri koi file mat khojo. Aapko poore saal sirf 2 files se baat karni hai: start-server (chalu karne ke liye) aur reports/ (mili report kholne ke liye). Baaki sab aapke peeche kaam karta hai.

Kitna jagah khayega?

Zip ~200 KB, kholne ke baad ~1 MB. Koi background process nahi, koi cloud nahi, koi subscription nahi. Aapki laptop par hi sab chalta hai.

1Step 1 — Zip kholo

1

Jo file download hui (viralytics-seo-live.zip), use kholo

Windows par: file par right-click → "Extract All…" → default jagah theek hai (Downloads) → Extract dabao. Ek folder ban jaayega jisme saari files hain.

Mac par: zip par double-click — folder apne aap khul jaayega.

Aapko kya dikhega: ek folder jisme start-server.cmd, index.html, USER-GUIDE.html, tools folder, aur kuch aur cheezein hain. Ye poora folder kahin aise hi rakho jahan wo move na ho — jaise Desktop par apna ek folder bana lo: Documents/Viralytics. Folder ki jagah tab badlegi jab server chalu ho, toh aage dikkat.

2Step 2 — Node.js install karo (free, 5 minute)

Node.js ek aisa chhota program hai jo dashboard ke "dimaag" ko chalata hai. Google par nodejs.org dhoondho (pehla result hi sahi hai).

2

Download karo

Website par bada green button hoga — "Download Node.js (Latest LTS version)". LTS wala hi lena hai (wohi default button hai).

3

Install karo — sirf Next dabate raho

Windows: file khulegi → Next → Next → Next → Install → Finish. Beech mein kuch bhi mat badlo, default hi sahi hai.

Mac: khuli file ko "Applications" folder par kheencho (drag karo).

Kaise pata chalega ki ho gaya: aapko kuch nahi dikhaya — Finish dabate hi ho gaya. (Aage Step 4 mein khud test ho jaayega — agar nahi install hua to start-server khud batayega, pareshani nahi.)

3Step 3 — Dashboard chalu karo (power button)

3

start-server double-click karo

Apne Viralytics folder mein jao. Windows: start-server.cmd par double-click. Mac: start-server.command par double-click.

Aapko kya dikhega: ek kaali terminal window khulegi (ya "yellow text ka box") jisme kuch lines likhi hongi, kuch aisi:
  Viralytics dashboard chalu ho raha hai...
  Browser khud khulega (http://localhost:8420).
  Band karne ke liye: bas ye window band karo.

  Viralytics live lookup  →  http://localhost:8420
  go.js v1 · read-only · local only
4

Browser khud khul jaayega

2 second mein aapka browser apne aap khulega aur dashboard dikhega — upar green dot ke saath "🔎 Website daalo" button hoga. Green dot = server saanv raha hai, sab theek.

Agar browser khud nahi khula to dar mat karo — address bar mein haath se likh do: localhost:8420 aur Enter. (Matlab "localhost" — apni hi laptop ka address. 8420 uska darwaza.)

Agar window likhe: "✗ Node.js nahi mila" → Step 2 dobara karo (Node install nahi hua tha).
Terminal window band mat karo (jab tak kaam chal raha ho)Yahi window server hai. Ye band karo to dashboard band. Kaam khatam ho to bas ye window band kar do — koi "stop" button nahi, itna hi. Kal dobara use, wahi double-click.

4Step 4 — Pehli report banao (3 minute)

5

Upar right corner ka "🔎 Website daalo" button dabao

Box khulega. Usme client ka naam likho — jaise sharmaclinic.in. http:// ya www. mat likho, bas naam. Neeche keywords ki jagah khali chhod do (pehli baar ke liye). "Dekho" dabao.

3 second mein: ek chhoti si report dikhegi — kitne pages dikhe, kitne toote hain, site ka title kya hai. Ye baat-cheet ke liye wali 3-second wali cheez hai — client ke saamne turant dikha sakte ho.
6

"Poori jaanch chalu karo → report file" dabao

3-4 minute lagenge (site ke pages jitne, utne). Tab tak aap client se baat karte raho.

Ho jaane par: do download buttons dikhenge — "live-​sharmaclinic.in.html download karo" aur "Action plan (.md)". Dono dabao. HTML file hi aapki report hai — client ko wahi bhejni hai.
7

Report file kholo — bas double-click

Jo live-sharmaclinic.in.html download hui, uspar double-click karo — browser mein poora dashboard khulega, client ke asli nambarn ke saath, bina internet ke bhi. Isme 10 tab hain — kya-kya dekhna hai wo main booklet (USER-GUIDE) mein hai.

Bas. Setup mukammal.Aaj se roz ka chakkar sirf itna hai: start-server double-click → kaam → window band. 10 second. Aur har client ke liye ek nayi report file — ek hi laptop par 10 clients ek saath.

6Uske baad ke din — routine

Har din (2 minute)

  • start-server double-click → browser khud
  • Overview tab dekho (score, trend, top kaam) — details USER-GUIDE ke Section 5–6 mein
  • Kaam khatam → terminal window band

Har mahine (client ke liye)

  • Box mein client ka domain → "Poori jaanch" → nayi report file
  • Reports tab → Print → PDF → client ko bhejo

Agar dashboard ka update aaye (nayi zip mile)

Purane kaam khooge nahi — aise badlo(1) Pehle reports/ aur out/ folder ka backup le lo (donon ko kahin copy karo). (2) Nayi zip kholo. (3) Purane folder ke reports/ aur out/ ko nayi jagah wapas rakh do (aapki report files + history wahi se aage chalti hai). Bas. Baaki files nayi wali hi use karo.

Completely khatam karna ho to?

Terminal window band karo, aur Viralytics folder delete kar do. Kisi doosri jagah kuch save nahi hota, koi account nahi, koi charge nahi.

7Security — aapke dimaag ki rahat

  • Koi data kahin nahi jaata. Sab aapki laptop par hi. reports/ folder hi aapka data hai.
  • Client ka koi password nahi chahiye. Dashboard sirf site ko padhta hai (jaise aap padhte ho). Google ke namber ke liye malik ko bas 2 minute ka CSV export dena hota hai — password kabhi nahi.
  • Site par likhta hi nahi. Dashboard kisi client site par kuch change nahi karta. Jo bhi change ho, wo insaan ki taraf se, client ki manzoori ke baad.
  • ₹0. Na software, na API, na subscription. Aapka kharch sirf electricity ka.
